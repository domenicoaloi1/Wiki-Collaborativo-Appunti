title Design Pattern: Protection Proxy

class Client {
}

interface Subject <<interface>> {
  + {abstract} request() : void
}

class RealSubject {
  + request() : void
}

class Proxy {
  - realSubject : RealSubject
  + request() : void
  - checkAccess() : Boolean
}

' --- RELAZIONI ---

' Realizzazione dell'interfaccia
Subject <|.. RealSubject : <<realize>>
Subject <|.. Proxy : <<realize>>

' Associazione tra Proxy e RealSubject
Proxy o--> RealSubject : - realSubject

' Dipendenza del Client verso l'astrazione
Client ..> Subject : <<use>>

note left of Proxy
 **request()** {
  if (checkAccess()) {
   realSubject.request()
  } else {
   throw AccessDeniedException
  }
 }
end note
