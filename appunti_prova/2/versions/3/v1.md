# Note sui Limiti - Parte 1

Il concetto di limite studia il comportamento di una funzione vicino a un punto.

## 1. Intorni
Un intorno $I(x_0)$ è un intervallo aperto contenente $x_0$.

## 2. Definizione di Limite
Si dice che:
$$\lim_{x \to x_0} f(x) = l$$
se per ogni intorno di $l$ esiste un intorno di $x_0$ tale che le immagini cadano nell'intorno di $l$.
