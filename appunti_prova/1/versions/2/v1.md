# Appunti Normalizzazione (Stesura Preliminare)

La normalizzazione serve a ridurre la ridondanza nei database relazionali.

## 1. Prima Forma Normale (1NF)
Una tabella è in 1NF se ogni colonna contiene valori atomici e ogni record è identificato da una Chiave Primaria.

## 2. Seconda Forma Normale (2NF)
Tutti gli attributi non chiave devono dipendere dall'intera chiave primaria.
